# Antes de comecar

Este manual cobre o pacote Docker do GoFacialEmulator. Antes de começar a
instalação, separe o que vai precisar.

## O que ter em mãos

- O arquivo `GoFacialEmulator-docker.zip`.
- Uma máquina com **Windows 10 ou 11**.
- Permissão de administrador nessa máquina, para instalar o Docker Desktop.
- Os dados de acesso ao banco do W-Access: endereço do servidor, usuário e
  senha. Você vai usá-los mais adiante, no capítulo Configurar o W-Access.

## Onde extrair o pacote

Extraia o ZIP em `C:\GoFacialEmulator`.

Evite extrair dentro de **Área de Trabalho**, **Documentos** ou de uma pasta
sincronizada pelo **OneDrive**. Essas pastas ficam sob sincronização
automática com a nuvem, e essa sincronização atrapalha o banco de dados do
emulador enquanto ele está em uso — o mesmo vale para os outros dois
pacotes, e por isso `C:\GoFacialEmulator` é o caminho recomendado em
qualquer um deles.

Com o pacote extraído no lugar certo, siga para o próximo capítulo:
instalar o Docker Desktop.
